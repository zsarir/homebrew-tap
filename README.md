# homebrew-tap

Homebrew formulae by [zsarir](https://github.com/zsarir).

```bash
brew install zsarir/tap/phase-console-pro
```

| Formula | What it is |
|---|---|
| `phase-console-pro` | [Phase Console](https://phase-console-site.vercel.app), the local web console and autopilot for the phased-execution Claude Code skill. It installs the prebuilt `phase-console-pro` package from the npm registry. The free features run as installed, and a license key unlocks Pro. |
| `phase-console` | Deprecated: replaced by `phase-console-pro`. |

`phase-console-pro` follows the npm package of the same name. The publish script of each release
writes its formula from a template and pushes it here, so change the template, never the formula.
