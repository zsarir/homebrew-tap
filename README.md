# homebrew-tap

Homebrew formulae by [zsarir](https://github.com/zsarir).

```bash
brew install zsarir/homebrew-tap/phase-console
```

| Formula | What it is |
|---|---|
| `phase-console` | Local web console for the [phased-execution](https://github.com/zsarir/phased-execution) Claude Code skill — installs from the npm registry tarball, client prebuilt. |

Versions track the `vX.Y.Z` tags of the source repository; the release workflow there opens a
bump PR here for each release.
